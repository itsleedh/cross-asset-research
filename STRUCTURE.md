# Recommended long-term structure

```text
.
├── _quarto.yml
├── index.qmd
├── research.qmd
├── about.qmd
├── references.bib
├── assets/
│   └── styles.css
├── reports/
│   └── dated full reports
├── posts/
│   └── YYYY-MM-topic/
│       └── index.qmd
└── .github/workflows/
    └── publish.yml
```

## Suggested taxonomy

- **Macro** — rates, FX, fiscal/monetary policy, cross-country flows
- **Markets** — cross-asset valuation and scenario work
- **Quant** — empirical research, signal tests, portfolio methods
- **Projects** — research tooling, data pipelines, experiments

## Publishing rule of thumb

Each flagship note should expose, near the top:

1. thesis;
2. strongest evidence;
3. falsification conditions;
4. catalysts/signposts;
5. asset implications;
6. full report / data / code.
